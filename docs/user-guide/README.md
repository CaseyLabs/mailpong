# Mailven user guide

This directory contains the end-user documentation for Mailven. It began as a copy of the upstream Aerion documentation site, [hkdb/aerion-docs](https://github.com/hkdb/aerion-docs/tree/main/docs), taken at commit `32cb76f01216cc990d15b2c9671710b12347493d`, and has since been rewritten for Mailven. It contains the Markdown and MDX guide pages only; the Docusaurus website source and build configuration are not included.
