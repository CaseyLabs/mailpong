# Installation

Mailven has no published releases yet. Until the first release, build it from source; each platform page below lists the steps. See the [Build Guide](../../../BUILD.md) for the full build instructions.

Everything Mailven stores lives in its own data directories and keyring entry, separate from Aerion. If you used Aerion before, see [Import from Aerion](../import-from-aerion.md).
